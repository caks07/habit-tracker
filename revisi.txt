# 1. AppFlowy — REFERENSI TERPENTING UNTUK SCHOLAR

[AppFlowy GitHub](https://github.com/AppFlowy-IO/AppFlowy?utm_source=chatgpt.com)

Ini yang paling saya rekomendasikan Anda **bedah mekaniknya**, bukan sekadar lihat tampilannya.

AppFlowy memang dibangun sebagai alternatif Notion dan memiliki konsep database dengan berbagai view. Repository utamanya sekarang sekitar **77k stars** dan sangat aktif. [GitHub](https://github.com/appflowy-io/appflowy?utm_source=chatgpt.com)

Yang menarik justru dokumentasi internalnya.

AppFlowy memodelkan database dengan konsep:

```text
Database
   │
   ├── Field
   │
   ├── Row
   │     ├── Cell
   │     ├── Cell
   │     └── Cell
   │
   ├── View
   │
   ├── Filter
   │
   └── Sort
```

Mereka secara eksplisit memisahkan **Row sebagai data**, **Field sebagai property**, dan **View sebagai cara menampilkan data**. Pada Kanban, setiap card sebenarnya merupakan row dari database yang sama. [GitHub](https://github.com/AppFlowy-IO/AppFlowy-Docs/blob/main/essential-documentation/contribute-to-appflowy/write-for-appflowy/drafts/draft-how-to-add-a-new-property-to-appflowy-database.md?utm_source=chatgpt.com)

Ini **persis masalah yang sedang Anda hadapi sekarang**.

### Yang harus Anda curi konsepnya

Bukan source code-nya, tetapi model:

```text
DATABASE
    ↓
ROWS / RECORDS
    ↓
VIEWS
    ↓
UI
```

Jadi:

```text
Schedule DB
 ├── Table View
 ├── Calendar View
 └── Board View
```

dan bukan:

```text
Dashboard Schedule Data
Schedule Table Data
Calendar Data
```

---

## Lebih menarik lagi: AppFlowy bahkan mengalami masalah yang sama dengan ide Anda

Ada issue di AFFiNE tentang **cross-page linked database** yang sangat mirip dengan yang Anda inginkan: satu database dibuat di suatu halaman, lalu ditampilkan di halaman lain sebagai linked view dengan filter berbeda. Diskusinya bahkan secara eksplisit membahas konsep yang setara dengan **Notion linked database**. [GitHub](https://github.com/toeverything/AFFiNE/discussions/12633?utm_source=chatgpt.com)

Artinya kebutuhan Anda bukan aneh atau overengineering. Ini memang salah satu masalah arsitektur inti aplikasi Notion-like.

### AppFlowy juga sudah memiliki:

- multiple database views
- Table
- Board
- Calendar
- Gallery
- List
- Chart
- Feed
- Relation
- Rollup
- advanced filters
- grouping
- database search
- row sebagai independent page
- drag/reorder view
- cover images [GitHub](https://github.com/AppFlowy-IO/AppFlowy/blob/main/CHANGELOG.md?utm_source=chatgpt.com)

Yang sangat relevan dengan permintaan Anda:

> **database row dapat menjadi page sendiri**

Ini cocok sekali dengan ide Anda bahwa card/activity bisa membuka detail dan tetap menjadi record asli.
